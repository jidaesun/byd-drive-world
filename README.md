# BYD DRIVE WORLD

브라우저에서 바로 접속하는 3D 멀티플레이 자동차 커뮤니티 MVP입니다.
차량을 고르고, 직접 운전해서 오너 라운지·세차장·카페·해안도로·튜닝샵을 돌아다니며 다른 접속자와 만날 수 있습니다.

> BYD와 무관한 **비공식 오너 커뮤니티** 프로젝트입니다. 제조사 로고나 공식 3D 에셋은 사용하지 않으며,
> 차량은 공개 제원(전장·전폭·전고·축거)의 비율만 참고해 직접 만든 캐주얼 스타일 모델입니다.

## 실행 방법

```bash
npm install        # ws, esbuild, typescript 설치
npm run build      # client → dist/ 번들
npm start          # http://localhost:3000 (정적 파일 + WebSocket 서버)
```

- 개발 모드: `npm run dev` (클라이언트 변경 시 자동 재빌드)
- 포트 변경: `PORT=8080 npm start`, 최대 동시 접속 인원: 기본 30명 (`MAX_PLAYERS=30`)
- 같은 주소를 휴대폰 두 대(또는 브라우저 탭 두 개)에서 열면 서로의 차량이 보입니다.
- `dist/standalone.html` 은 서버 없이 열 수 있는 단일 파일입니다(오프라인·혼자 드라이브 모드).

## 조작 (모바일 전용)

모바일 브라우저(세로·가로 모두)를 기준으로 만들었습니다. PC에서 열어도 같은 터치 UI가 표시됩니다.

| 동작 | 방법 |
|---|---|
| 조향 | 왼쪽 아래 조이스틱 (기울인 만큼 조향) |
| 가속 | 오른쪽 아래 가속 버튼 |
| 브레이크 / 후진 | 브레이크 버튼 (정지 후 계속 누르면 후진) |
| 경적 | 📯 버튼 |
| 카메라 | 화면 드래그 |
| 목적지 안내 · 내 차량 · 채팅 | 왼쪽 위 📍 🚗 💬 버튼 |

## 구현된 기능

**1단계 — 플레이 가능한 3D 프로토타입**
- 타원형 섬 월드: 오너 라운지(분수·전시 포디움·주차선·포토존), 셀프 세차장(3베이), 감성 카페(테라스·주차장), 섬 일주 오션뷰 드라이브 코스(전망대·부두), 튜닝샵(턴테이블)
- 차량 4종(ATTO 3 / SEAL / DOLPHIN / SEALION 7) — 모델별 크기·실루엣이 다른 절차적 3D 모델
- 운전 물리(가감속, 속도 감응 조향, 롤/피치 연출), 건물·나무·차량 충돌, 섬 경계 처리
- 추적 카메라(드래그 회전, 줌, 자동 복귀), 낮·노을·밤 시간대 순환, 실시간 그림자, 바다·구름·별
- 세차: 거품 → 고압수 → 광택 3단계, 주행하면 다시 오염, 청결도 표시
- 목적지 안내: 장소를 고르면 순간이동하지 않고 핀·방향 화살표·남은 거리를 표시, 직접 운전해서 찾아감
- 차종 고정: 처음 선택한 차량으로 고정되며 튜닝샵에서는 꾸미기만 가능 (현재는 기기 저장 기준, 계정 도입 후 서버에서 고정)
- 사진 저장

**2단계 — 멀티플레이 (기본)**
- Node.js + WebSocket 서버: 접속/퇴장, 15Hz 위치 동기화와 보간, 닉네임 이름표
- 전체 / 주변(45m) 채팅, 말풍선, 경적·이모트 동기화
- 실제 접속자 수만 표시(가짜 접속자 없음), 서버가 없으면 "오프라인" 으로 명시
- 서버 측 입력 검증, 속도 제한, 정원 제한(30명), 끊어진 연결 정리

**3단계 — 커스터마이징 (일부)**
- 차체 색상(화이트·그레이·블랙), 투톤 루프, 휠 디자인 4종·휠 색상, 데칼 5종·데칼 색상, 번호판 색상
- 변경 즉시 3D 차량에 반영, 차량별로 브라우저에 저장, 다른 접속자에게 동기화

## 아직 구현되지 않은 기능

- 회원가입·로그인, BYD 오너 인증, 관리자 승인 (UI에는 "미인증 · 데모" 로만 표시)
- 개인 메시지, 친구, 모임 개설, 신고·차단
- 스티커 이미지, 번호판 문구, 앞유리·후면 장식, 서버 저장 차고
- 서버 권위 이동 검증(현재는 클라이언트 위치를 범위 검사 후 중계)
- 부하 테스트, 프로덕션 배포, 도메인 연결

## 기술 구성

| 영역 | 사용 기술 |
|---|---|
| 클라이언트 | TypeScript, 자체 WebGL2 렌더러(그림자 맵·하늘·바다·파티클), esbuild |
| 서버 | Node.js `http` + `ws` |
| 에셋 | 전부 코드로 생성(외부 모델·텍스처·폰트 없음) |

의뢰서의 추천 스택(Three.js / React / Rapier / Socket.IO / Supabase)은 초기 개발 환경에서 패키지를 설치할 수 없어 사용하지 않았습니다.
렌더링(`renderer.ts`)과 게임 로직(`main.ts`, `world.ts`, `cars.ts`)이 분리되어 있어 이후 Three.js·React Three Fiber로 옮길 수 있습니다.

```
client/index.html, style.css   UI
client/src/main.ts             게임 루프, 운전, 카메라, UI, 세차
client/src/renderer.ts         WebGL2 렌더러와 셰이더
client/src/world.ts            월드 지형·건물·충돌체
client/src/cars.ts             차량 4종 모델, 꾸미기 데이터
client/src/net.ts              멀티플레이 클라이언트
server/server.mjs              정적 서버 + 실시간 서버
scripts/build.mjs              빌드
```

## 배포

실시간 서버는 지속 연결이 필요하므로 서버리스 함수가 아닌 상시 실행 환경에 올립니다.

- **가장 간단한 방법**: Render / Railway / Fly.io 등에 이 저장소를 연결 → Build `npm install && npm run build`, Start `npm start`. 한 서비스가 페이지와 WebSocket을 함께 제공합니다.
- **분리 배포**: `dist/` 를 Vercel 등 정적 호스팅에 올리고, 서버만 별도로 실행한 뒤 `https://내사이트/?server=wss://내서버/ws` 로 접속하거나 `index.html` 에 `window.BDW_SERVER = 'wss://…/ws'` 를 지정합니다.
